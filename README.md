# 🎙️ Piper Local TTS Web UI

Локальный веб-интерфейс для нейросетевого синтеза речи (Text-to-Speech) на базе движка **Piper** (архитектура **VITS** + **ONNX Runtime**).

Работает полностью автономно на вашем компьютере, без отправки данных в интернет. Поддерживает работу как на обычном **CPU**, так и с аппаратным ускорением на **GPU (NVIDIA CUDA)**.

---

## 🚀 Быстрый старт

Просто дважды кликните по файлу:

```text
start.bat
```

Скрипт автоматически:
1. Проверит наличие Python в системе.
2. Создаст изолированное виртуальное окружение (`.venv`).
3. Установит все необходимые библиотеки из `requirements.txt`.
4. Скачает базовую русскую модель голоса (`ru_RU-dmitri-medium`), если она отсутствует.
5. Запустит веб-сервер и откроет страницу в браузере (по умолчанию `http://127.0.0.1:7860` или следующий свободный порт).

## 🗣️ Поддерживаемые голоса

В интерфейсе доступны готовые пресеты:
* **Русские голоса**:
  * `ru_RU-dmitri-medium` (мужской)
  * `ru_RU-irina-medium` (женский)
  * `ru_RU-ruslan-medium` (мужской)
  * `ru_RU-denis-medium` (мужской)
* **Английский голос**:
  * `en_US-lessac-medium` (женский)

> 💡 **Автозагрузка:** при выборе нового голоса из выпадающего списка веб-интерфейс автоматически скачает его с Hugging Face в папку `voices/`.

### Добавление других языков и голосов
Вы можете скачать любые другие голоса (доступно более 170 голосов на 40+ языках) из официального репозитория [rhasspy/piper-voices на Hugging Face](https://huggingface.co/rhasspy/piper-voices/tree/main). 
Для каждого голоса скачайте два файла (`.onnx` и `.onnx.json`) и поместите их в папку `voices/`.

## ⚙️ Параметры генерации

В интерфейсе доступны параметры:
* **Устройство вычислений (CPU / GPU)**: переключение между процессором и видеокартой NVIDIA (CUDA).
* **Скорость речи**: ускорение или замедление воспроизведения (1.0 — стандартная).
* **Вариативность интонации (`noise_scale`)**: влияет на живость и эмоциональные перепады тона (по умолчанию `0.667`).
* **Вариативность длительности фонем (`noise_w_scale`)**: влияет на естественность ритма и пауз между звуками (по умолчанию `0.8`).
